# 🛒 AppMandi

**AppMandi** is a personal app showcase and distribution platform - my own custom Play Store! Built entirely with HTML, CSS, and JavaScript.

---

## 🚀 Features

- 🎨 Custom landing page with featured apps
- 📱 Individual pages for each app with:
  - App details
  - Download button
  - Screenshots & description
  - Developer notes and GitHub links
- 🗂️ Organized folder structure per app
- 📥 Direct APK hosting and download
- 💬 Hinglish tone + cute & creative UI

---

## 📁 Folder Structure

```
AppMandi/
├── index.html
├── style.css
├── script.js
├── app1/
│ ├── app1.html
│ ├── app1.css
│ ├── app1.js
│ └── assets/
│ ├── apk/
│ └── images/
├── app2/
│ └── ...
```

Each app has its own folder, HTML page, assets, and download link.

---

## ⚙️ Tech Stack

- HTML, CSS, JS (Vanilla)
- Mobile-first responsive design
- Hosted statically with GitHub Pages

---

## 💡 Idea Behind It

> I wanted a cute, custom place to host all my Android creations - like my own indie app store. AppMandi is playful, personal, and developer-focused. 🌱
