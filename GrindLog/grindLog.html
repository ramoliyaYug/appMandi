Why GrindLog? 🤔

GrindLog is built for every serious coder who’s grinding through LeetCode, Codeforces, GFG and more. Track your daily goals, log your progress, and analyze everything — all in one place!

🗓️

Today Tracker

Log what you’ve solved today on each platform with completion percentage and notes.

Contest Reminders

Set reminders for contests or custom events with local notifications 1 hour before.

📊

Advanced Analytics

Visual breakdown of platform-wise progress filtered by week/month/year.

To-Do Progress

Daily to-dos with completion tracking and productivity stats.

📥 Download & Installation

System Requirements

  • 📱 Android 8.0 (API level 26) or higher
  • 💾 30 MB free storage space
  • 🚫 No internet needed after install

Installation Instructions

  1. Download the APK file
  2. Go to Settings → Security → Unknown Sources
  3. Enable "Install unknown apps"
  4. Open the downloaded APK file
  5. Tap "Install" and start grinding! 💪
